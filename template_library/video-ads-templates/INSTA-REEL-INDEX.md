# Instagram reel reference library

Seven reel formats, derived from 13 reels supplied on 24 Sep 2026, each in its own
`insta-friendly` folder with a breakdown of the format, why it works, how to shoot it,
and how to adapt it for an Indian residential developer.

These seven sit alongside the twelve Canva ad categories in this folder, numbered 13 to 19
so the two sets stay grouped rather than interleaving.

## What is in each folder

| File | What it is |
|---|---|
| `README.md` | The format: what it is, why it works, the reference reels, how to adapt it |
| `PRODUCTION-SPEC.md` | **The shootable version.** Shot list, on-site prep, frame-accurate beat timing, text and lockup placement, caption. Hand this to a videographer. |
| `DISCOVERED.md` | Further reels in the same format, found beyond your original 13 |
| `DOWNLOAD-LIST.txt` | Every URL paired with the filename to save it under |

`INSTA-PRODUCTION-NOTES.md` at this level holds the rules common to all seven: Instagram safe
areas, the price and MahaRERA lockup geometry, artist-impression disclaimer wording, audio
policy, export settings, caption skeleton. Read it once before the specs.

**43 reels are on disk.** Each folder holds the reference videos themselves, named to
match the notes about them, plus a `REELS-ON-DISK.md` mapping every file back to its
source post and the reason it was picked. The full catalogue of 73 found reels stays in
each folder's `DOWNLOAD-LIST.txt`, so the ones not yet pulled down can be added later
without rediscovering them. `INSTA-HOW-TO-DOWNLOAD.md` covers that, and covers what you
may and may not do with someone else's reel.

## Suggested order of work

1. Read `INSTA-PRODUCTION-NOTES.md`. Build the price and MahaRERA lockup once in Canva at
   1080 x 1920 and save it as a reusable element. Everything else depends on it.
2. Run 19 (drone construction progress) on your next site visit. It is 20 minutes, it
   sets the flight log, and the flight log is the thing you cannot create retrospectively.
3. Run 16 (presenter price reveal) on your strongest active site. Highest ceiling of the
   seven, and you already have the presenter and the location.
4. Run 13 (AI land-to-home) on the next plot you launch, while it is still bare. Once
   excavation starts you have lost the "before" plate for that site permanently.
5. 14, 15, 17, 18 as the inventory calls for them.

Items 2 and 4 are time-sensitive in a way the others are not. A bare plot and a
pre-foundation site are both perishable assets.
