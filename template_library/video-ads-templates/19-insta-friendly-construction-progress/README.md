# Construction progress

## The format

Aerial pass over the live site with the project name locked up on screen and a short progress line.

## Why it works

Lowest effort, lowest ceiling, highest trust. Engagement is modest but it is the format that keeps existing buyers calm and gives channel partners something to forward. Run it monthly per project.

## How to shoot it

- Same flight path, same height, same time of day, every month. The comparison over time is the asset.
- Project name lockup in a fixed position so the series reads as a series.
- One progress fact: floors cast, slab level, block completed.
- Do not over-edit. Credibility comes from it looking like a record, not an ad.

## Adapting it for an Indian residential developer

- Feeds your existing 10-construction-update video category.
- Archive every month. At handover you have a year of footage for a land-to-home cut, which loops back to category 01.
