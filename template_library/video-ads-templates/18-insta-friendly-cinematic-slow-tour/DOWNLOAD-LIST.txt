HOW TO USE THIS FILE
--------------------
Copy a URL below, paste it into a downloader (fastvideosave.net or any
equivalent paste-a-link service), download the file, then rename it to
the "save as:" name printed directly under that URL and drop it in this
folder.

Work top to bottom. The list is already in the order you want, so the
numbering comes out right on its own.

Faster: download a whole batch into Downloads first without renaming,
then rename them all in one pass. Explorer sorts by download time and
this list is in the same order, so they line up row for row.

If a link is refused by the downloader, screen record it instead, or
skip it. There are more references here than you need.

Full walkthrough, including the no-download option and the rules on
what you can and cannot do with someone else's reel:
  ..\INSTA-HOW-TO-DOWNLOAD.md
