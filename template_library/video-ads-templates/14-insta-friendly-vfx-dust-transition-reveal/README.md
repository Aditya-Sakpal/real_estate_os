# VFX dust / smoke transition reveal

## The format

A dust cloud, smoke burst or debris sweep crosses frame and the finished building is standing when it clears.

## Why it works

Same payoff as the transformation format but far cheaper: you need one shot of the finished building and one transition element. The dust hides the cut, so no AI generation is required. Comment sections on these are full of people asking for the template, which is itself the engagement engine.

## How to shoot it

- 'Wait for the transition' as the opening super is doing real work. It buys you the first 2 seconds.
- Shoot the finished building (or render) from the same lens height and angle as the site plate.
- Dust and debris elements are stock; the match-move is what sells it. Lock the tripod.
- Put the project name, location and area in the caption as a spec block. Ozora does this and it reads as a portfolio entry, not an ad.

## Adapting it for an Indian residential developer

- Best fit for possession, handover and project-completion announcements.
- Works for a single tower reveal where the land-to-home format would be too slow.
