# Templates by tier

`<tier>/<status>/<images|carousels|videos>/<template>/`

Tiers: `affordable`, `upper-mid` (premium later). Status: `under-construction`,
`ready-to-move`. English only.

Every video set has the walkthrough (Agent on camera) and the narrated story.

Each template folder holds references from other developers' posts and a README with
their links. They are for development only: before going live each is replaced by
our own AI-made versions (at least three per template), and the references are
removed.
